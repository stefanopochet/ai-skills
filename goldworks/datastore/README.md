# gw/ — where Goldworks keeps its state

Copy this folder to `<your-repo>/gw/`, then copy the area configs you want from `../miners/` into
`gw/miners/`. Everything Goldworks knows lives here in plain markdown: **the folder is the state**, moving
a file is the transition, and `git diff` shows what happened.

```
gw/
├── opportunities/
│   ├── new/            cards just deposited by the miners (evidence only, no verdict)
│   └── dismissed/      killed — every file keeps the reason and a revisit trigger. Not a graveyard:
│                       miners dedup against it, the judge revisits it when a trigger fires
├── issues/             one file = one issue
│   ├── backlog/        survived the triage, not urgent
│   ├── todo/           promoted with the owner's explicit approval
│   ├── on-hold/        waiting on someone — always with a follow_up date or a trigger
│   ├── done/           closed
│   └── cancelled/      killed after promotion, with the reason
├── context/            the world pre-miner's output: world-YYYY-MM-DD-raw.md and -extract.md
├── miners/             one config per area (copy them here), plus optional <area>.context.md
├── runs/               run files: YYYY-MM-DD-gw.md and YYYY-MM-DD-miner-<area>.md
├── INDEX.md            the menu — regenerated by the judge every run, never edited by hand
├── calibration.md      the rules of judgment, plus the archive of the owner's verdicts
└── state.json          run guard: run_date, run_status, miner_last_run; add gw_pause to stop the judge
```

## Who moves what

| Transition | Who | When |
|---|---|---|
| `new/` → `dismissed/` | the judge | triage, default outcome |
| `new/` → a new issue in `backlog/` | the judge | when a card survives (evidence copied into the issue) |
| `backlog/` → `todo/` | the judge **proposes**, the owner approves; the session that gets the yes moves it | promotion |
| any → `on-hold/` and back | the judge | when someone else is awaited / when the timer or trigger fires |
| `todo/` → `done/` | the session in which the owner closes it | at closure |
| any → `cancelled/` (with the reason) | the judge, on the owner's verdict or a declared rule | at the verdict |

## Rules that hold this together

- **Whoever generates does not judge**: miners and judge in separate contexts.
- **Ground truth**: every promotion rests on verified evidence; no negative claim without positive proof.
- **Models**: judge = Claude Fable 5 `xhigh`, always. Miners = Claude Opus 5 `xhigh`.
- **The owner's attention**: one lens, "they need to know this", a few lines at most.
